## Data availability:
Palimpsest folios from Codex XL are publicly available here: https://digitallibrary.univr.it/annona/?iiif-content=https://digitallibrary.univr.it/manifests/CPVRm0040_1.json 

The synthetic data is generated online. Code is available inside biden2_model.
